# Phase 01 — Foundation & Architecture

## Objective
Establish the JalRakshak architecture without implementing feature screens.

## Implement
- package structure
- theme/design-system foundation
- repository/data-source interfaces
- domain boundaries
- ViewModel/state conventions
- Navigation 3 foundation
- adaptive/window-size foundation
- test structure
- centralized configuration

## Constraints
No complete feature UI, backend, actual ESP32 implementation or UI safety logic.


## Checkpoint
Run the required build/tests, report changed files, results, deviations and known issues, then STOP and wait for human approval.
