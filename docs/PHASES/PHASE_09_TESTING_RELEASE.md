# Phase 09 — Final Testing, Responsive Audit & Judge Release

## Objective
Produce a stable hackathon demonstration build.

## Test
- clean build and APK
- navigation and all four screens
- Demo Mode and safety transitions
- outlet lock on unsafe/fault/offline
- compact/medium/expanded layouts
- light/dark themes
- offline operation
- truth audit: Calcite/Limestone present, 10 W solar consistent, no SIM800L, no fake contaminant readings, DEMO MODE visible
- complete 2-minute judge flow

Record exact final configuration, test results and known issues. Do not begin unrelated feature work after this phase.


## Checkpoint
Run the required build/tests, report changed files, results, deviations and known issues, then STOP and wait for human approval.
