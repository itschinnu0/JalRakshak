# Phase 02 — Design System & App Shell

## Objective
Create the reusable premium visual language and adaptive app shell.

## Implement
- light/dark JalRakshak theme
- typography, spacing, shapes, semantic safety colors
- reusable cards/surfaces/buttons/status components
- adaptive scaffold
- custom hybrid navigation
- status/alert treatment
- localization foundation
- DEMO MODE treatment
- logo/brand placeholder

## Requirement
Premium environmental-tech + futuristic monitoring; not stock Material. Use window size classes, never device-specific dimensions.


## Checkpoint
Run the required build/tests, report changed files, results, deviations and known issues, then STOP and wait for human approval.
