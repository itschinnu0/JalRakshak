# Phase 00 — Project, Git & AI Agent Setup

## Objective
Create a clean Android Studio baseline and configure the AI Coding Agent without implementing JalRakshak features.

## Tasks
- Android project: `JalRakshak`
- Package: `com.jalrakshak.app`
- Kotlin + Jetpack Compose + Kotlin DSL
- minSdk 34, compileSdk 37, targetSdk 37
- Verify Gradle sync and clean build
- Run untouched app on Android 14
- Initialize Git
- Put `AGENTS.md` at project root and copy documentation
- Verify Gemini Agent Mode

## Constraints
No backend, BLE, Firebase, Room, networking or feature implementation.


## Checkpoint
Run the required build/tests, report changed files, results, deviations and known issues, then STOP and wait for human approval.
