# Phase 06 — Insights & Analytics

## Objective
Build interactive local analytics from deterministic simulation history.

## Implement with Vico
- parameter switch
- touch tooltip
- threshold visualization
- event markers
- event timeline

Parameters: pH, turbidity, TDS, temperature.

Charts represent simulated/demo history until hardware exists. Do not fabricate unsupported contaminant charts.


## Checkpoint
Run the required build/tests, report changed files, results, deviations and known issues, then STOP and wait for human approval.
