# Phase 05 — Purification Experience

## Objective
Create the interactive treatment pipeline and stage explanations.

## Required order
Raw Water -> PP/Sand -> Calcite/Limestone -> Aeration -> Fe/Mn Media -> Appropriate Adsorption -> UF -> UV-C -> Outlet Monitoring -> Solenoid

## Implement
Interactive nodes, active/complete/upcoming states, connecting flow, stage details, accurate descriptions and responsive layout.

## Constraints
Calcite/Limestone is neutralization before Fe/Mn. Appropriate Adsorption is not universal heavy-metal removal. Prefer custom Compose Canvas over generic node-graph dependencies.


## Checkpoint
Run the required build/tests, report changed files, results, deviations and known issues, then STOP and wait for human approval.
