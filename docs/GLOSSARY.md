# GLOSSARY

AMD: acid mine drainage. Calcite/Limestone neutralization: acidity-neutralization stage before Fe/Mn treatment. Fe/Mn Media: iron/manganese treatment media. Appropriate Adsorption: contaminant-specific adsorption. UF: ultrafiltration. UV-C: ultraviolet-C. TDS: dissolved-solids indication, not individual contaminant detection. Fail-safe: outlet defaults closed in unsafe/fault/offline states. Source-risk profile: contextual risk, not a live sensor reading. Demo Mode: explicit simulated operation.
