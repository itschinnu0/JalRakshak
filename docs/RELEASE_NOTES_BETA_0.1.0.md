# JalRakshak Beta 0.1.0 Release Notes

- First signed beta release
- Smart water purification and quality monitoring prototype
- Deterministic offline demo mode
- Real-time pH / turbidity / TDS / temperature quality monitoring
- Interactive treatment pipeline visualization (Raw water -> PP/Sand -> Calcite/Limestone -> Aeration -> Fe/Mn Media -> Appropriate Adsorption -> UF -> UV-C -> Outlet Monitoring -> Solenoid)
- Safety-state simulation & dynamic outlet control
- System diagnostics & sensor status
- Insights and water quality trends
- Known prototype limitation: onboard sensors do not individually detect heavy metals or pathogens; laboratory validation remains required
- Approximate prototype BOM: ₹8,000
- ESP32 hardware integration remains future scope
